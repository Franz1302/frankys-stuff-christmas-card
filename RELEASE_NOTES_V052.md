# Franky's Seasonal Fun Card v0.5.2

## Christmas: Santa, Christkind or both

Choose **Santa**, **Christkind** or **Both** directly on the card under **Options → Who should appear?**. In Both mode, independent schedules are coordinated so the figures never appear simultaneously. The choice is saved separately in each browser.

The visual editor provides per-figure enable switches, appearance frequency, time range, animation size, sound level and separate test controls. Child lock also protects the on-card selection.

The Christkind appears as a transparent 15-second animation with embedded audio, entering from the left edge of the screen. Its media file is bundled in the release.

## Compatibility and upgrading

Existing Christmas Card and Seasonal Fun Card HACS installations update in place. No second repository or extra card is required. Christmas, Halloween, St. Martin, St. Nicholas, the calendar and existing design settings remain available.

After upgrading, reload the dashboard page once. Browser restrictions on automatic sound playback still apply. Conversion for older iOS browsers is intentionally deferred until there is demand.
